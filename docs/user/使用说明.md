# X-Plane 12 飞行教学汉化 · 使用说明

> ⚠️ **ARM64 包（`win-arm64` / `linux-arm64`）未经实机测试**：使用前请先备份原版并先用「预演」确认；
> 详见仓库 `AGENT.md` §9。

## 打补丁（3 步）

1. **完全退出 X-Plane 12**
2. 双击 `XPlane12-FlightLessons-zh-CN.exe`
3. 点 **「打补丁」**，弹出窗口点 **「继续」**

等它显示绿色的 **「补丁完成」** 就好了 —— 开游戏，进「飞行教学」，
课程标题和字幕就是中文了。

> 程序会自动找到游戏目录。找不到就点「浏览…」，
> 选到**有 `X-Plane.exe`（Windows/Proton）或 `X-Plane-x86_64`（Linux 原生版）的那一层文件夹**
> （通常是 `…\steamapps\common\X-Plane 12`）。程序会自动识别可执行文件类型。

> Windows 压缩包里有一个 `[解压后再运行]` 空文件，提醒你**先把整个文件夹解压出来**，再双击其中的 exe。

## 还原英文

- 程序里点 **「还原原版」**；或
- Steam → 右键 X-Plane 12 → 属性 → 已安装文件 → **验证游戏文件完整性**

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 打完还是英文 | 确认看到「补丁完成」；彻底退出游戏再进一次 |
| 提示「未验证版本」 | 游戏更新了，勾选确认可以继续；出问题就还原 |
| 提示「没有权限」 | 按弹窗提示，选「以管理员身份重启」 |
| 中文显示成方块 | Steam 验证文件完整性（修复游戏自带字体），不用装系统字体 |
| 游戏更新后失效 | Steam 更新会覆盖补丁，重新打一次 |
| 提示游戏正在运行 | 先完全关闭游戏（含后台）再打 |

## 程序生成的文件

都在程序旁边的 `.zh_cn_translate` 文件夹里（原版备份、日志、补丁报告）。
整个文件夹可以随时删掉，不影响游戏。

## Linux（Steam / Proton 与 Linux 原生版）

```bash
# 按你的架构二选一：
tar xzf XPlane12-FlightLessons-zh-CN-linux-x64.tar.gz -C ~/apps/xpzhcn   # x64
# tar xzf XPlane12-FlightLessons-zh-CN-linux-arm64.tar.gz -C ~/apps/xpzhcn  # ARM64（ARMv8-A / arm64-v8a）

chmod +x ~/apps/xpzhcn/XPlane12-FlightLessons-zh-CN
~/apps/xpzhcn/XPlane12-FlightLessons-zh-CN
```

> **ARM64 电脑（⚠️ 未经实机测试）**：Windows on ARM 用 `XPlane12-FlightLessons-zh-CN-win-arm64.zip`，
> ARM64 Linux 用 `XPlane12-FlightLessons-zh-CN-linux-arm64.tar.gz`，用法与 x64 包相同；
> 风险说明见仓库 `AGENT.md` §9。

操作和 Windows 完全一样，程序会自动检测：

- **Linux 原生版**（Steam 默认装的 `X-Plane-x86_64`）→ 直接打补丁；
- **Steam/Proton/Wine**（目录里的 `X-Plane.exe`）→ 和 Windows 版一样打补丁；
- 两个文件都在时，Linux 上优先处理原生版（窗口里会显示正在处理哪个文件）。

Steam Deck 请切到**桌面模式**运行。
